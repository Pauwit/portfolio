# Phase 2a: Home Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the real Home page: hero (headline, subtext, links, CV download, Contact CTA), a 5-project flagship grid using the grid-locked asymmetry layout system, and a real Open Graph preview image, replacing Phase 1's placeholder content.

**Architecture:** Astro static page assembling four real, library-sourced React islands (Spotlight, Text Effect, 3D Card, Card Flip) plus real project content authored into the Content Layer collections from Phase 1. No new framework/architecture decisions — this phase is content + component integration on top of the Phase 1 foundation.

**Tech Stack:** Astro 5, React 19 islands, Tailwind CSS v4, `motion` (already a dependency from the Navbar retrofit), shadcn CLI for component installs, `sharp` (new, for OG image generation).

## Global Constraints

(Copied verbatim from `docs/specs/2026-07-25-portfolio-design.md` — every task below implicitly inherits these.)

- Palette — dark: bg `#100C08`, surface `#1C1712`, text `#EFECE8`, accent `#95122C`. Light: bg `#F7F5F4`, surface `#ECE8E6`, text `#100C08`, accent `#95122C` (same accent both themes, never used for small body text).
- Typography — Clash Display (headlines) via `font-display`, Switzer (body) via `font-body`. No monospace.
- Radius — `rounded-card` (12px) for cards/panels/images-in-cards, `rounded-chip` (8px) for buttons/chips/nav pills. Never the bare `rounded`/`rounded-sm`.
- `prefers-reduced-motion` — every animated component needs a static fallback via the existing `prefersReducedMotion()` helper (`src/lib/reducedMotion.ts`).
- Layout system — grid-locked asymmetry: a 12-column grid, content spans vary in width, every block shares one consistent left margin. No mechanical left-right alternation.
- Commit convention — Conventional Commits, single-line subject only, no body, no co-author trailer.
- **Component sourcing — every named library component must be genuinely installed and adapted from its real source, never reconstructed from a description.** This was violated once already (the Navbar) and caught in review; do not repeat it. If an install command in this plan is stale or the registry has moved, stop and ask for a current one rather than approximating the component's behavior by hand. A component that merely resembles the real one (same visual result, different underlying mechanism) is a plan failure, not an acceptable substitute.
- Copy rules (from the original brief and reinforced by this session's taste-skill pass): no em-dashes anywhere in site copy (hyphens only), no filler verbs ("elevate", "seamless", "unleash", "revolutionize"), no invented/fake-precise statistics, hero headline max 2 lines, hero subtext max 20 words, one CTA per intent (this page's only intents are "Contact" and "Download CV" — never introduce a synonym like "Get in touch" or "Let's talk" alongside "Contact").
- No analytics wired yet (unchanged from Phase 1).

- [ ] **Step 3: Create `scripts/generate-og-image.mjs`**

```js
import sharp from 'sharp';
import { readFileSync } from 'node:fs';
import { fileURLToPath } from 'node:url';
import { dirname, join } from 'node:path';

const __dirname = dirname(fileURLToPath(import.meta.url));
const svgPath = join(__dirname, '..', 'public', 'og-source.svg');
const outPath = join(__dirname, '..', 'public', 'og-image.png');

const svg = readFileSync(svgPath);
await sharp(svg, { density: 144 }).png().toFile(outPath);

console.log(`Generated ${outPath}`);
```
